## トラック（3 種）

### Classic「From Scratch」
- **すべての作業をハッカソン開始後に開始**。事前のプロジェクト固有コード・デザイン・アセットは不可（公開ライブラリ・スターターキットは可）。
- 事前構築物でも参加は可能だが、**partner prize と Finalist 選出の対象外**になる。

### Continuity（既存プロジェクト拡張）
- 既存コードベース上で作業可能。
- 提出時に **既存作業を明確にドキュメント化** し、**ハッカソン中に開発した新機能・新機能性を含める**こと。
- partner prize の対象可否はイベント・パートナーごとに異なる（各スポンサーの Continuity トラック参照）。

## 提出要件

- **GitHub リポジトリ / Figma / 同等の「イベント中の作業証跡」** を含める。
- 新規作業と再利用作業を明確に区別する。
- **バージョン管理でイベント中のコードを追跡する。巨大な単一コミット・履歴欠落は失格になりうる。**
- **partner prize は提出時に最大 3 つ選択可**。各パートナーツールをどう統合したか説明し、フィードバックを提供する。

### デモ動画（必須）

| 規定 | 内容 |
|---|---|
| 長さ | **2〜4 分**（範囲外は自動却下・再提出） |
| 解像度 | 最低 720p |
| 音声 | クリアな音声（背景ノイズ・エコー回避）、**話者によるナレーション必須** |
| 禁止 | TTS / AI 音声、スマホ録画、動画の速度操作 |
| スライド | 1 枚あたり箇条書き 4 点まで、イントロは 20 秒以内 |

### AI ツール利用ポリシー
- ChatGPT / Claude Code / Copilot / Cursor 等の利用は **概ね許可**。
- 提出物に **AI 支援を明記** する。
- 「AI はプロセス支援に使うもので、プロジェクト全体を生成させない」。
- **spec-driven ワークフローは許可**。ただし **spec ファイルとプロンプトをすべてリポジトリに含める**こと。
  → 本リポジトリの Spec Kit 成果物（`specs/`・`.specify/`）はそのまま提出資産になる。

## 審査

### プロセス（async 2 ラウンド）
1. **第 1 ラウンド:** 全プロジェクトを非同期スクリーニング。
2. 上位 **約 20%** がライブ審査へ進出。第 1 ラウンド結果は partner prize 資格に影響しない。
3. **ライブ審査（選出時）:** 1 チーム **7 分** = デモ 4 分 + Q&A 3 分。green room で待機してから審査ルームへ。
4. **partner prize は非同期審査**。応募者側のアクションは不要。

### 審査基準（5 カテゴリ）
| 基準 | 内容 |
|---|---|
| **Technicality** | 問題の複雑さと解法の洗練度 |
| **Originality** | 新しいアイデア・創造的な問題解決 |
| **Practicality** | プロジェクトの完成度・現時点での使用可能性 |
| **Usability (UI/UX/DX)** | 直感性・操作の容易さ |
| **WOW Factor** | 他カテゴリに収まらない独自性・印象度 |

## 戦略への含意

- **9/13 12:00 EDT が唯一の絶対締切。** 逆算タイムラインの終点はここ。日本時間では 9/14（日）午前 1:00 JST。
- **partner prize 3 枠選択制** は過去 ETHGlobal と同じ運用。本リポジトリの本命は The Graph / Hedera / Privy（`truecollective-prize-fit.md`）。
- **async 形式ゆえデモ動画とリポジトリ品質が生命線。** 現地の盛り上がりで押せない。2〜4 分・話者ナレーション・720p・速度操作なしを最初から設計する。
- **コミット履歴が審査対象。** day1 からこまめにコミット。「AI で一括生成 → 単一コミット」は失格リスク。
- **spec / プロンプトの同梱が明示的に要求されている。** Spec Kit ワークフローはこの回のルールと完全に整合。`specs/NNN-*/` を提出物に含める。
- **Finalist（本体賞）を狙うならライブ審査の 4 分デモ**。partner prize だけなら非同期で完結。両にらみが基本。
